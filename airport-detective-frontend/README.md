# 遗留物检测 Demo

遗留物检测、风险研判、原持有人回溯与处置闭环演示，使用三段车厢视频素材进行前端展示。

---

## 环境要求

- Node.js >= 18（推荐 22.x）
- npm >= 9

---

## 安装依赖

```powershell
npm install
```

当前项目没有额外第三方依赖，执行该命令主要用于生成本地 npm 环境文件。

---

## 启动开发服务器

```powershell
npm run dev
```

启动后浏览器访问 http://localhost:5173

如果 5173 端口已被占用，服务会自动尝试 5174、5175 等后续端口，请以终端输出的访问地址为准。

---

## 构建生产包

```powershell
npm run build
```

产物输出到 `dist/` 目录。

---

## 本地预览生产包

```powershell
npm run preview
```

访问 http://localhost:4173
