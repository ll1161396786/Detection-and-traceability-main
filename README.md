# 接驳车遗留物检测与溯源系统

Windows本地检测项目，包含统一前端、多路YOLOv10检测及本地警报档案。应用版本字段为1.1.0，实际改动日期和发布状态以测试台账为准。

项目文档统一为：

- [部署操作手册](部署操作手册.md)：环境要求、按GPU配置、启动、视频接入、通讯、报警、照片、回放与数据维护。
- [测试台账记录](测试台账记录.md)：近期改动、实际测试结果、已知问题、复测与发布记录；后续更新继续追加。

后续修改必须同步维护测试台账；操作步骤变化同时更新部署手册，不再另建独立版本/功能/验证手册。业务视频、照片与检测缓存仅本地配置。GitHub只在用户明确要求后同步。
